# Working & Teaching with QGIS

Source for the **Working & Teaching with QGIS** module of the [Workshop 2026](https://spatialturn.github.io/workshop2026.html) materials, part of [Enabling the Geospatial Turn in the Social Sciences](https://spatialturn.github.io/).
Published at <https://spatialturn.github.io/Workshop2026-Session1A/>.

An introduction to the QGIS interface, finding and loading vector data from public repositories, and basic cartography, with additional reading on map design.

The lesson is built with [The Carpentries Workbench](https://carpentries.github.io/sandpaper-docs/).
It is kept as it was taught at the workshop (Day 1, Session A QGIS track, part 1).

| Episode file | Title |
|---|---|
| `episodes/imageryvector.md` | Acquiring Vector Datasets from Data Repositories |
| `episodes/qgisintro.md` | Exercise 1a: Acquiring Data and Making Your First Map in QGIS |
| `episodes/additional-reading.md` | Additional Reading |

`data/airports.zip` holds the five parts of the Alaska airports shapefile from the
[QGIS sample data](https://github.com/qgis/QGIS-Sample-Data) (added October 2026 so learners download one file
instead of five).
